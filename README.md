# 寻己 · Find Your Calling

基于八木仁平《如何找到想做的事》核心理论，融合 IKIGAI、霍兰德、价值观澄清等多理论体系，帮助你系统性地找到真正想做的事。

## 核心公式

**喜欢 × 擅长 × 重要 = 真正想做的事**

## 探索流程

1. 破除误区 —— 先卸下常见的思维包袱
2. 价值观排序 —— 什么对你最重要
3. 擅长模式识别 —— 你自然比别人做得好的事
4. 喜欢领域探索 —— 什么让你忘了时间
5. 交叉分析 —— 喜欢 × 擅长 × 重要 交汇出的候选方向
6. 报告预览 —— 可导出 PDF

## AI 深度分析

支持接入阿里云百炼、DeepSeek、智谱 GLM 等大模型，完成测评后由 AI 给出个性化方向解读。

## 技术栈

纯前端 HTML + CSS + 原生 JavaScript，无构建工具。数据全存本地浏览器，无需注册。
